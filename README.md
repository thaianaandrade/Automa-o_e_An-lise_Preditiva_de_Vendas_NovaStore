## 📌 Visão Geral do Projeto
Este projeto integra o *Portfólio Tríplice de Análise de Dados da NovaStore, focando-se no processamento, automação e visualização estatística de dados de vendas utilizando a linguagem **Python*[span_2](start_span)[span_2](end_span). 

Após a modelação relacional e consultas RFM realizadas em MySQL (Projeto 2), este script automatiza o cálculo de métricas de desempenho comercial (Faturamento Total, Ticket Médio e Volume de Pedidos) e gera gráficos corporativos prontos para tomada de decisão[span_3](start_span)[span_3](end_span)[span_4](start_span)[span_4](end_span).

## 📊 Principais Resultados e Métricas Calculadas
Com base no processamento dos dados transacionais, a análise automática revelou as seguintes métricas gerais da NovaStore:

* *Faturamento Total:* 17.950,00 €
* *Número Total de Pedidos:* 10 transações
* *Ticket Médio:* 1.795,00 €

### 💡 Insights Principais:
1. *Cliente VIP (Top Spender):* A cliente *Ana Carvalho (C0001)* lidera isoladamente o volume de receita com *7.700 €* acumulados[span_6](start_span)[span_6](end_span)[span_7](start_span)[span_7](end_span).
2. *Segundo Maior Comprador:* O cliente *Daniel Ribeiro (C0002)* gera a segunda maior contribuição comercial com *4.850 €*[span_8](start_span)[span_8](end_span).
3. *Distribuição de Vendas:* Apenas 2 clientes representam a maioria do faturamento total da empresa, evidenciando a necessidade de estratégias de retenção para estes perfis VIP.
